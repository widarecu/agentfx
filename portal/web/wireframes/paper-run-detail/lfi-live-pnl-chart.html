X-axis strategy — calendar date + weekday (Mon 13 / Tue 14…) at day granularity for 7d view; falls back to hour tick labels (13:00 / 14:00…) at 24h view. Zoom range changes tick spacing via _pickAxisTicks(startMs, endMs).
Weekend shading — light-grey band drawn from Fri 22:00 UTC → Sun 22:00 UTC. Explicit visual so a flat curve during the gap doesn't look like a broken strategy. Also drawn for any equity gap > 6h from _detectGaps().
Snapshot reference — dashed horizontal line at snapshotBalance. Above = profit, below = loss.
Hover crosshair — vertical line follows mouse X. Nearest equity sample located via _binarySearchNearestPoint(series, targetMs). Tooltip pinned inside chart bounds (flips to the left if it would overflow).
Trade markers — ▲/▼ live on the timeline, not on the curve, so the equity shape stays legible. Exit dots sit ON the curve, coloured by realised P&L sign. Hovering a marker swaps the tooltip content for trade details.

5 · Interaction map
  • Hover on chart body → crosshair + tooltip with equity, drift, unrealised, realised, elapsed, trade count-to-date.
  • Hover on ▲/▼/● → tooltip swaps to trade detail (side, entry/exit timestamp, entry/exit price, pips, P&L, exit reason, signal reason).
  • Click ▲/▼/● → scrolls the page to that row in the trades table (highlighted for 2s).
  • Range pills (24h / 7d / All) → client-side filter on equity[] and trades[]. No new network request.
  • Keyboard — 1 = 24h, 2 = 7d, A = All, ←/→ nudges the crosshair by one sample.
