Pass A — Low-fi wireframes

AgentFX v0.6.0 · Paper Trading

Grayscale, annotated wireframes for the six flows that ship in v0.6.0. Purpose: lock information hierarchy, page sequence, and interaction states before we invest in visual polish or backend engineering. Every flow has a matching high-fidelity mockup in the ../mockups/ directory.

  1. [ empty /paper → banner → /settings → verified ]
    Flow 1 · First-time TRADER onboarding 3 screens

    Empty state → set OANDA credentials → verified → nudge to approval queue.

  2. [ cards per VALIDATED genome → Approve → Deploy modal ]
    Flow 2 · Approval queue 2 screens

    Queue of AWAITING_APPROVAL genomes → deploy modal collecting name / balance / risk knobs.

  3. [ header · metrics grid · live-vs-backtest chart · panels ]
    Flow 3 · Live monitoring (the money view) 1 dense screen

    Status pill, kill button, metrics grid, live-vs-backtest equity overlay, positions, trades, decisions.

  4. [ big red button → toast 3s countdown → HALTED ]
    Flow 4 · Kill switch 3 states

    Idle → 3-second undo toast → HALTED_MANUAL transition.

  5. [ tabs: Profile · OANDA Credentials · (coming soon) ]
    Flow 5 · Settings / credentials 3 credential states

    Empty → set-not-verified → set-and-verified. Form with masked API key and PRACTICE-only radio.

  6. [ ADMIN toggle: My runs / All runs · owner badges ]
    Flow 6 · Multi-user visibility (ADMIN) 1 screen, 2 modes

    Scope toggle in the header. Owner email badges surfaced on rows, detail header, and queue cards.

Wireframe conventions
  • Dashed borders = placeholder region. Solid borders = final container.
  • Boxed uppercase text like [STATUS] = dynamic content.
  • Annotations sit in the right margin, prefixed with ◂.
  • Colors are grayscale on purpose — semantic red/green comes in Pass B mockups.
