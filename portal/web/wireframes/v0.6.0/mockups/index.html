v2 Changes from Wilson's answers (2026-07-05)
  • Accounts concept added. Credentials store the OANDA API key; the accounts under that key are fetched via /v3/accounts. Deploy modal picks an account and reads its balance live. AgentFX never asks the user for an "initial balance" — that's set inside OANDA.
  • Snapshot balance. Run's P&L % denominator is the account balance at the moment the paper runner starts, not a user-typed number.
  • Trades table gains a Signal reason column. DSL entry rule + exit cause (TP / SL / opposite / kill) per trade.
  • LivePnLChart is now dual-x-axis. Bottom = relative hours since run start; top = actual UTC timestamp.
  • Reject reason is required (≥ 10 chars) with quick-pick chips.
  • Approval queue empty state added as a positive affirmation with recent-activity strip.
  • Concurrency indicator — amber banner appears at 10+ concurrent paper runs, explains broker quota headroom.
  • Nav placement unchanged (fine per Wilson); owner badge stays indigo.
Design language notes
  • Palette: slate for chrome; emerald for pass / positive P&L; rose for fail / kill switch; amber for warnings.
  • Dark-mode support baked in via dark: variants — matches the existing portal.
  • Reused components are called out by name (KillSwitchButton, LivePnLChart, CredentialsForm, TradesTable, StrategyChart, MetricsCard, ApprovalQueueCard, DeployPaperModal) — see the README component inventory.
  • Fake data is deterministic across mockups so numbers are consistent room-to-room.
