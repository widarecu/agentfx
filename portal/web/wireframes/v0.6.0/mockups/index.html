Design language notes
  • Palette: slate for chrome; emerald for pass / positive P&L; rose for fail / kill switch; amber for warnings.
  • Dark-mode support baked in via dark: variants — matches the existing portal.
  • Reused components are called out by name (KillSwitchButton, LivePnLChart, CredentialsForm, TradesTable, StrategyChart, MetricsCard, ApprovalQueueCard, DeployPaperModal) — see the README component inventory.
  • Fake data is deterministic across mockups so numbers are consistent room-to-room.
