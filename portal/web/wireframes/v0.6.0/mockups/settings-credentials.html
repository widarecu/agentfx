The API key is encrypted at rest using Fernet (AES-128-CBC + HMAC-SHA256). Only the paper runner subprocess decrypts it in memory; the plaintext never appears in any API response or log line. Account balances are queried from OANDA on demand — they are not persisted in AgentFX.
