# Architecture Decision Record (ADR)

ID: ADR-0001
Date: <YYYY-MM-DD>
Context:
We will enforce a gated pipeline (Gate A: spec/ADR, Gate B: validation) and paper-first rollout for autonomous strategies.

Decision:
Adopt feature flags and a promotion process: dev → paper (≥ 2 weeks, thresholds) → live. Only immutable, validated strategy artifacts can run live.

Alternatives:
Direct-to-live; partial validation. Rejected due to risk.

Consequences:
Requires policy engine, flags, provenance, CI checks, and monitoring alignment.
