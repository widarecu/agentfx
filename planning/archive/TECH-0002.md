# Technical Enabler (TECH)

ID: TECH-0002
Owner: Wilson Reyes
Purpose: Minimal service API and persistence for metrics/results
Scope:
- REST API to serve strategies, positions, PnL, metrics, recent decisions
- Persistence: SQLite (MVP) with option to move to Postgres
- Data model includes strategy, run, decision, order, position, metric
- AuthN: simple token-based; no secrets in client; least privilege
