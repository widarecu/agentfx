# Feature (FEAT) Template

Title: FEAT-0001 — Market data ingestion (majors, 1m bars)
Status: approved
Owner: Wilson Reyes
Related: BUS-0001, SYS-0001, TECH-0001

## Context
Ingest major FX pairs with 1m bars for research, backtesting, and paper/live. Primary provider: OANDA.

## Scope
- In scope
  - Connect to data provider, fetch/store 1m OHLCV for majors
  - Data validation, gap detection, retries
  - Versioned storage and access API
- Out of scope
  - Tick-level ingestion (future)

## Acceptance Criteria
- Given a configured set of major pairs, when the pipeline runs, then ≥ 180 days of 1m bars are available and validated.
- Given market hours, when new bars arrive, then they are appended within 60s.

## Non-Functional Needs
- Latency: batch acceptable
- Data retention: per NFRS
- Observability: metrics for ingestion rates, errors

## Dependencies
- TECH-0001 (storage/config)

## Risks & Controls
- Data gaps → gap detection and backfill
