# Test Plan

ID: TEST-0001
Scope: Validate OANDA Practice 1m OHLCV ingestion for major FX pairs with backfill, continuous updates, and data quality.
Test Types: unit, integration, system
Datasets: OANDA instruments (EURUSD, GBPUSD, USDJPY, USDCHF, AUDUSD, USDCAD, NZDUSD), granularity=M1, UTC
Pass/Fail Thresholds:
- Unit: timestamp parsing, pagination, file/db writes pass 100%
- Integration: ingest last 2 days for 2 pairs completes with 0 NaNs, monotonic timestamps, expected count within ±1% of theoretical
- System: initial backfill (≤ 365 days) per pair completes without fatal error; gap detection + backfill closes all gaps ≥ 2 minutes
- SLA: append new bar within 60s of close; retry/backoff keeps error rate < 1% over 1 hour
Runbook Impact: document env vars, rate limits, and backfill steps
Links: FEAT-0001
