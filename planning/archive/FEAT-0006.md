# Feature (FEAT)

Title: FEAT-0006 — Read-only User Portal
Status: proposed
Owner: Wilson Reyes
Related: BUS-0001, SYS-0001, TECH-0002, FEAT-0005

## Context
Provide a minimal web portal to view strategy status, positions, PnL, and key metrics from paper runs (and later live).

## Scope
- In scope
  - Read-only dashboard: strategy list, current status (enabled/disabled), environment (dev/paper/live)
  - Metrics: PnL (daily/cumulative), Sharpe, MDD, hit rate, order latency
  - Views for recent decisions/logs with provenance IDs
  - Authentication (basic) and role: viewer
- Out of scope
  - Trade controls (enable/disable strategies) — later

## Acceptance Criteria
- Given paper runs are active, when the user opens the portal, then strategy metrics and recent activity are visible within the last minute.
- Given a strategy is selected, when viewing details, then positions, recent orders, and decision logs are displayed.

## Non-Functional Needs
- Simple deployment; low-latency reads (< 1s p95) from metrics store
- No secrets in client; API protected

## Dependencies
- TECH-0002 (API + persistence)
- FEAT-0005 (paper metrics generation)

## Risks & Controls
- Data staleness → last-updated indicators and auto-refresh

## Compliance
- [ ] Architecture Principles reviewed
- [ ] NFRs impact assessed
- [ ] Security Constraints verified

## Validation Plan
- TEST-0006: populate mock data; verify dashboards render and refresh; sanity-check metrics

## UI Requirements — Chart & Overlays (Strategy Detail)
- Candlestick chart with timeframe controls: supports M1, M5, M15, H1; default M5.
- Range controls: 1d, 7d, 30d; draggable/zoomable; preserves viewport across auto-refresh.
- Trades and Orders:
  - Show Trades table (round-trips) by default for backtests; optional synthetic Orders.
  - Orders table visible where available (paper/live) with execution details.
- Overlays (extensible):
  - Strategy signals rendered via a generic overlay schema (lines, bands, oscillators, markers).
  - Initial overlays: MA (fast/slow lines with cross markers), RSI (oscillator with bands). Donchian next.
- Tooltips on trade exit markers include: side, size, entry ts/price, exit ts/price, gross PnL, net PnL, return %, duration, MAE, MFE, provenance/trace ID.
- Position band: background shading for in-position intervals (long/short).
- Auto-refresh interval: 60s.
- Downsampling: cap responses at 10k points; apply time-based sampling when above cap.

## Metrics Additions (per trade)
- MAE (Maximum Adverse Excursion): largest unrealized loss during a trade (price/pips/%; optionally ATR multiples).
- MFE (Maximum Favorable Excursion): largest unrealized profit during a trade (price/pips/%; optionally ATR multiples).

## API Requirements — Resources and Endpoints (Read-only)
### Market Data (strategy-agnostic)
- GET /api/pairs/{pair}/candles?tf=M1|M5|M15|H1&from=ISO&to=ISO&limit=5000
  - Returns: timestamp, open, high, low, close, volume.

### Runs (execution context)
- GET /api/runs?env=paper&pair=AUDUSD&strategy=ma&status=enabled&limit=100&cursor=...
  - Returns: list of runs with pair, strategy, env, status, params, last_updated, summary metrics.
- GET /api/runs/{run_id}
  - Returns: run metadata (pair, strategy_id, env, params), last_updated, summary metrics.

### Run-scoped Artifacts (strategy-specific)
- GET /api/runs/{run_id}/trades?from=ISO&to=ISO&limit=1000&cursor=...
  - Returns: trade_id, entry_ts, entry_price, exit_ts, exit_price, side, qty, gross_pnl, net_pnl, return_pct, duration_s, mae, mfe, provenance_id.
- GET /api/runs/{run_id}/orders?from=ISO&to=ISO&limit=1000&cursor=...
  - Returns: order/execution feed; synthetic for backtest; real for paper/live.
- GET /api/runs/{run_id}/signals?from=ISO&to=ISO&limit=5000&series=...
  - Returns: generic overlay series (e.g., ma_fast/ma_slow lines, rsi oscillator, donchian bands) aligned to candles.
- GET /api/runs/{run_id}/position_bands?from=ISO&to=ISO
  - Returns: intervals of in-position with side for chart shading.

### Strategies Catalog (metadata)
- GET /api/strategies?env&status&q&limit&cursor
  - Returns: list of strategies with defaults and supported overlays.
- GET /api/strategies/{strategy_id}
  - Returns: strategy metadata and default parameters.
- GET /api/strategies/{strategy_id}/latest-run?env=paper&pair=AUDUSD
  - Convenience: returns the latest run_id to link dashboard → detail.

## Acceptance Criteria — Chart Addendum
- Candles render at selected timeframe and range with responsive performance; downsampling engages beyond 10k points.
- All trades in range show entry/exit markers connected by lines; tooltips display MAE/MFE and net PnL metrics.
- Selected overlays (MA/RSI) align with position changes; overlay system accepts new strategy signals without UI changes.
- Auto-refresh updates underlying data within 60s without disrupting the user’s current viewport.
