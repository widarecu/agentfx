# Planning and Governance

This folder contains the lightweight, repo-native planning system.

- Workflow: proposed → approved → in-progress → validating → paper → live → done
- IDs: BUS-, SYS-, FEAT-, TECH-, RISK-, ADR-, EXP-
- Gate A: FEAT approved (acceptance criteria + ADR if needed)
- Gate B: Validation complete (Test Plan + EXP results ≥ thresholds)
